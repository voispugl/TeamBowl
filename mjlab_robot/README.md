Team bowl capstone robot MJlab simulation

To install libraries, use uv

on mac(assuming you have brew installed):

'
brew install uv
'


on linux

'
curl -LsSf https://astral.sh/uv/install.sh | sh
'

then enter into the mjlab folder and run 

' 
uv add mjlab
'

On linux, verify it works with: 

'uv run demo;


unclear how to run on mac as of this point...
